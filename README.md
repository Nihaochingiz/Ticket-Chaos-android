# Тикетный Ад

Сатирическая текстовая RPG для Android о буднях сотрудника первой линии
технической поддержки. Разбирайте абсурдные обращения, берегите последнюю
нервную клетку и постарайтесь дожить до конца смены.

## Скачать APK

**[Скачать «Тикетный Ад» 1.1.1](https://github.com/Nihaochingiz/Ticket-Chaos-android/raw/refs/heads/main/Ticket-Hell-1.1.1.apk)**

Требуется Android 7.0 или новее. Приложение работает полностью офлайн.

> **18+:** игра содержит ненормативную лексику, грубый офисный юмор и
> саркастические шутки. Все персонажи и события вымышлены.

## Установка на Android

1. Откройте ссылку скачивания на телефоне.
2. Дождитесь загрузки `Ticket-Hell-1.1.1.apk`.
3. Откройте загруженный файл.
4. Если Android заблокирует установку, разрешите браузеру или файловому
   менеджеру **установку неизвестных приложений**.
5. Нажмите **Установить**, затем запустите **Тикетный Ад**.

Google Play Protect может показать предупреждение, поскольку APK распространяется
напрямую через GitHub, а не через Google Play.

## Возможности

- Полностью русский интерфейс.
- 14 основных сюжетных эпизодов.
- 5 различных концовок.
- Характеристики психики, терпения, кофе и репутации.
- Выборы, изменяющие дальнейшее прохождение.
- Автоматическое локальное сохранение.
- Продолжение последней смены.
- Оригинальная игровая иллюстрация.
- Собственная Android-иконка с Николаем вместо стандартного логотипа Flutter.
- Отсутствие регистрации, рекламы и подключения к серверу.

## Правила

Вы играете за Николая — специалиста первой линии поддержки. В каждом эпизоде
выбирайте один из ответов. Решения изменяют характеристики героя:

- **Психика** — способность сохранять связь с реальностью.
- **Терпение** — запас вежливости для пользователей.
- **Кофе** — внутренний источник питания.
- **Репутация** — мнение руководства о ваших сомнительных методах.

Если психика или терпение закончатся, герой выгорит. При нулевой репутации его
уволят. Другие решения открывают основные и секретные концовки.

## Сборка проекта

### Требования

- Flutter 3.50 или новее;
- Dart 3.14 или новее;
- JDK 17;
- Android SDK;
- Android-устройство или эмулятор для запуска.

### Команды

```bash
git clone https://github.com/Nihaochingiz/Ticket-Chaos-android.git
cd Ticket-Chaos-android
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Собранный APK появится по адресу:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## Технологии

- Flutter и Dart;
- Material 3;
- `shared_preferences` для локального сохранения;
- Android package: `com.tickethell.game`;
- Minimum SDK: Android 7.0 / API 24;
- Target SDK: API 36.

## Приватность

Игра не собирает и не отправляет персональные данные. Прогресс хранится только
на устройстве пользователя. При удалении приложения сохранение также удаляется.
